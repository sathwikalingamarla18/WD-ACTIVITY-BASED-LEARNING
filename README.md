The Project Management Dashboard helps users organize projects, track progress, manage tasks, and view team member information through a structured dashboard interface.

### Features
- Project summary cards
- Total projects and task statistics
- Project progress bars
- Kanban task board
- To Do, In Progress, and Completed sections
- High, Medium, and Low priority labels
- Team member details
- CSS Grid and Flexbox layouts
- Hover effects and animations
- Responsive design for smaller screens

### Technologies Used
- HTML
- CSS
